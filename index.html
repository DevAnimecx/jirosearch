Frequently asked questions

Everything you need to know about licensing, performance, architecture, and compliance.

What is Jiro Search?

Jiro Search is an open-source, MIT-licensed, self-hosted search API that provides web search across 9 engines, social media scraping for 12 platforms, AI synthesis with citations, and a built-in MCP server for AI agents. It is a free alternative to SerpAPI, Apify, and Tavily.

Is Jiro Search free?

Yes. Jiro is MIT licensed and free to self-host. Install with pip install jirosearch and run it locally with no API keys required. A managed Pro tier starts at $29/month for residential proxies, CAPTCHA solving, and AEO tracking.

How does Jiro compare to SerpAPI?

Jiro is self-hosted and MIT licensed; SerpAPI is a paid cloud service. Jiro supports 9 search engines with automatic fallback, 12 social media scrapers, an MCP server, hybrid search with semantic reranking, and AI synthesis. SerpAPI costs $75-500/month; Jiro is free.

What search engines does Jiro support?

Jiro supports 9 search engines: Google, Bing, DuckDuckGo, Brave, YouTube, Amazon, eBay, Yandex, and Baidu — with automatic fallback and circuit breakers. It also includes 6 plugin engines: Google Scholar, arXiv, GitHub, Wikipedia, Hacker News, and Reddit.

Does Jiro work with Claude Desktop and MCP?

Yes. Jiro includes a built-in MCP server with 17 tools. It works with Claude Desktop, Cursor, and any MCP-compatible agent. Add {"mcpServers":{"jiro":{"command":"jiro","args":["mcp"]}}} to your Claude config. Supports stdio, HTTP, and SSE transports.

Can Jiro scrape social media without API keys?

Yes. Jiro scrapes 12 social platforms using public endpoints and HTML parsing, not official APIs. No API keys required. Each platform has fallback chains — for example, Twitter uses FxTwitter, then Nitter, then Playwright as a browser fallback.

Does Jiro require an LLM API key for AI synthesis?

No. Jiro includes extractive synthesis that works with zero LLM API keys. It summarizes answers from search results with citations in 0.03ms. If you provide an OpenAI or Anthropic key, it uses the LLM for higher quality, but it is not required.

What is Jiro's hybrid search?

Jiro's hybrid search combines keyword matching, semantic vector similarity, and SERP signals into one ranked result set. It uses Reciprocal Rank Fusion and a cross-encoder reranker with an 80MB embedding model that runs on CPU — no GPU required.

How do I install Jiro Search?

Install with pip install jirosearch. Start the API server with jiro serve (available at http://localhost:8000 with docs at /docs). For MCP, run jiro mcp. Docker: docker-compose up -d.

What license does Jiro use?

Jiro uses the MIT license — commercial use, modification, distribution, and private use with no restrictions. Unlike AGPL-licensed projects like Firecrawl, you do not need to open-source your own product when using Jiro.

Is Jiro production ready?

Jiro includes Docker, Kubernetes Helm chart, OpenAPI 3.1 spec, SDK generation (Python/TypeScript/Go), Prometheus metrics, structured logging, SQLite and PostgreSQL backends, Redis rate limiting, SSRF protection, robots.txt compliance, and audit logging. 494 tests.
