# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅ |
| < Latest | ❌ |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in the Jiro landing page or infrastructure, please **do not open a public GitHub issue**.

Instead, report it privately:

- **GitHub Security Advisories**: use the "Security" tab → "Report a vulnerability"
- **Email**: security@blackvault.dev

We will acknowledge within **48 hours** and aim for a fix within **7 days** for critical issues.

## Scope

This repository contains the Jiro landing page (jiro.dev). For vulnerabilities in the Jiro Search API itself, see the [main repository](https://github.com/DevAnimecx/jiro/security).

## Responsible Use

Jiro is a web search and scraping tool. Users are responsible for complying with each search engine's Terms of Service, `robots.txt`, and applicable law.
