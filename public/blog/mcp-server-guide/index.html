How to Give Claude Desktop Web Search with an MCP Server

By Adarsh Kushwah • September 2, 2026 • 6 min read

Anthropic's Model Context Protocol (MCP) has revolutionized how AI agents interact with local tools, external data, and APIs. Instead of fragile prompt engineering and bespoke function definitions, MCP establishes an open, bi-directional JSON-RPC protocol.

Out of the box, Claude Desktop cannot browse the live internet unless equipped with an MCP server. In this guide, you will configure Jiro's built-in MCP server, giving Claude instant access to 17 tools: multi-engine search, direct webpage markdown extraction, Reddit post retrieval, Twitter feeds, and extractive answer synthesis.

What Tools Does Jiro Expose to MCP?

Jiro's MCP implementation includes 17 discrete tools across three transport modes (stdio, HTTP, and SSE):

  • search_web: Query Google, Bing, DuckDuckGo, or Brave with intent detection.
  • search_social: Pull live posts from Reddit, Twitter, Bluesky, TikTok, and YouTube.
  • scrape_markdown: Convert any URL into clean, LLM-ready markdown in sub-100ms.
  • synthesize_answer: Get extracted answers with verified citations without external LLM keys.
  • extract_json: Extract typed JSON structures from raw webpage contents based on a provided schema.

Step 1: Install Jiro Search

Install the Jiro package in your local Python environment (Python 3.11 or newer is required):

pip install jirosearch

Step 2: Configure Claude Desktop

Locate your Claude Desktop configuration file:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json

Add the Jiro MCP server configuration under the mcpServers key:

{ "mcpServers": { "jiro": { "command": "jiro", "args": ["mcp", "--transport", "stdio"] } } }
Pro-tip for Cursor & Windsurf: You can use the exact same configuration block inside your mcp.json for Cursor IDE to empower your code editor with real-time web documentation search.

Step 3: Restart Claude and Test Your Setup

Completely quit and restart Claude Desktop. You will notice the hammer icon in the bottom right corner showing 17 tools active.

Try prompting Claude with:

"Search Google and Reddit for the latest updates on Python 3.13 free-threading benchmarks, and extract the summary with source citations."

Claude will automatically invoke jiro.search_web and jiro.search_social, returning grounded, timely facts with zero hallucinations.

Transports: Stdio vs HTTP vs SSE

While stdio is ideal for single-user desktop apps like Claude Desktop, Jiro also supports distributed multi-agent workflows using Server-Sent Events (SSE) or HTTP transports:

# Launch as an HTTP / SSE server for LangChain, CrewAI, or AutoGen jiro mcp --transport sse --port 8080 --host 0.0.0.0

Summary

By connecting Jiro to Claude Desktop via MCP, you unlock limitless web access without third-party subscriptions or privacy concerns. All queries remain strictly on your local machine or private cloud cluster.
